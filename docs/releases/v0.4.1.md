## 这版做了什么

- 在插件市场里搜「搜索」「文件搜索」「本地搜索」「全文检索」「docx」，现在能看到这个插件了——以前搜不到，因为市场是按字面匹配的，而插件的介绍里写的是「检索」。
- 插件自己的介绍（配置卡片、插件列表、npm 页）统一成同一句：本机文件搜索与文档全文检索。
- 换了一枚新图标：文档是主体，放大镜是从纸上挖出来的洞，纸上三行内容。
- 没有改任何工具、参数、配置键或错误码，0.4.0 的 profile 直接升。

## 怎么做到的

- 目录条目与各处介绍里补上「文件搜索 / 全文搜索 / 全文检索」和 PDF / DOCX / XLSX / PPTX / EPUB 这些实际会被输入的词。
- README 的同类介绍从一串外链改成一张三行对比表，读者一眼能看出它和另外两个插件的差别。
- 图标用同一份几何同时导出 SVG 与 PNG，目录站要的位图不再靠另一份手稿。

```

## What changed

- Searching the plugin market for 搜索, 文件搜索, 本地搜索, 全文检索 or docx now finds this plugin. It used to match nothing: the market matches literally, and the description said 检索 instead.
- The plugin's own introduction (configuration card, plugin list, npm page) now says the same thing everywhere: local file search and document full-text search.
- A new mark: the document is the subject, the magnifier is a hole cut out of the paper, three lines sit on the page.
- No tool, argument, config key or error code changed; a 0.4.0 profile upgrades as-is.

## How

- The catalog entry and the descriptions now carry the words people actually type — file search, full-text search, document search — plus the extensions PDF / DOCX / XLSX / PPTX / EPUB.
- README's related-plugins section became a three-row comparison table instead of a list of outbound links.
- The icon is one geometry exported twice, so the SVG and the PNG the catalog needs cannot drift apart.

## Upgrade

dsh plugin --profile <profile> add @fishdivinity/dsh-local-search
```

## Compatibility

- DSH `>=0.2.1-0 <0.3.0`; still Windows with Everything (`es.exe`) and Anytxt.
- Tool names, arguments, error codes and config keys are unchanged; this release moves the introduction, the icon and the version number.
