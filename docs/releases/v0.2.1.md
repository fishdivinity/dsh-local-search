## Highlights

- A closed Everything window now reports the engine as unavailable instead of "no files found": `es.exe` exits 1 both for "nothing matched" and for a dead connection, and only the output tells them apart.
- The configuration page's Test control names the missing link — Everything not installed, installed but not running, or `es.exe` missing — instead of always suggesting a download. A check that cannot run says `unknown` and keeps the generic hint, rather than telling you to install what you already have.

## Changes

- `search`: a capped page whose hits were all filtered (`$RECYCLE.BIN`, `System Volume Information`) says the window was capped rather than claiming there are no matches; the cap is measured before the filter.
- `status`: a cancelled probe reads as `ABORTED — <CODE>`, not `DOWN`.
- `scopes`: `scope=all` drops roots nested inside another root, so AnyTxt's per-root counts are not summed twice.
- `engines`: the missing-link detail exists only on the page-only probe route; the model-facing status keeps its two stable codes and its short fallback hint.
- `limits`: the hard caps moved to `lib/limits.js`, with a test pinning the page's copies and the loopback host list to the Host's own rules.
- `prompt`: the routing section is 227 characters instead of 447, with the same four decisions.
- `release`: published release bodies expand relative links to `blob/<tag>/` URLs, so the repository copy keeps working relative links.

## Install / upgrade

```sh
dsh plugin --profile <profile> add @fishdivinity/dsh-local-search
```

## Compatibility

- DSH `>=0.2.1-0 <0.3.0`; no tool name, argument, error code, or configuration key changed, so a 0.2.0 profile upgrades without edits.
- Windows only; engine prerequisites are unchanged.
