## 这版做了什么

- 插件开始认识它所在的机器：平台、路径写法、可检索的根各只算一次；两个引擎探测出四态（正常 / 缺工具 / 缺索引 / 不可用），30 多个错误码各有修法。
- 出问题时，卡片描述下面可以**复制一份诊断**贴进 issue：版本、平台、每个后端的 code 与地址、配置、检索根、首启写回结果都在里面，家目录已换成 `~`。
- 每次启动会探一次引擎；有后端没起来时右下角出一张卡，一行一个后端、各自挂修法。不想被提醒就把「启动时检查」关掉。
- 附带 `de` / `es` / `fr` / `ja` / `pt` / `ru` 六种界面语言（DSH 0.2.2 起可选）。
- 默认检索范围改为**整台电脑**；可在配置页改成当前工作区、工作目录或个人目录。

## 怎么做到的

- 平台事实收进 `lib/platform.js`；探测收进各后端，`lib/probe.js` 只汇总归一，给模型和给人的输出分成两条面。
- 页面从 `describe` 拿到字段、类型、上限与后端列表；路径改写、失焦校验、测试连接共用同一套规则。
- 语言包按语言拆成文件、按需加载；基线中英文仍在 bundle 里，首屏不等网络。

## What changed

- The plugin now knows the machine it lives on: platform, path spelling and searchable roots are computed once, and both engines report four states (ready / missing tool / missing index / down) with a fix for each of 30+ error codes.
- When something fails, **Copy diagnostics** under the card description gives a text you can paste into an issue: versions, platform, each backend's code and address, configuration, roots and the startup-write result, with the home directory reduced to `~`.
- Every start probes both engines once; a failed backend shows a card in the corner with one line per backend and its own fix. Turn off **Check engines on startup** to stop the reminder.
- Ships `de` / `es` / `fr` / `ja` / `pt` / `ru` interface languages (selectable from DSH 0.2.2).
- The default scope is now **the whole computer**; switch it to the current workspace, work or personal folder on the configuration card.

## How

- Platform facts live in `lib/platform.js`; each backend owns its probe and `lib/probe.js` only aggregates, keeping the model-facing and user-facing outputs apart.
- The page renders fields, types, caps and backends from `describe`; path rewriting, blur checks and Test connection share one rule set.
- Locale packs are per-language files loaded on demand; Chinese and English stay in the bundle so the first frame does not wait on the network.

## Upgrade

```sh
dsh plugin --profile <profile> add @fishdivinity/dsh-local-search
```

## Compatibility

- DSH `>=0.2.1-0 <0.3.0`; still Windows with Everything (`es.exe`) and/or Anytxt.
- 0.1 / 0.2 flat config keys are migrated into the nested structure on startup and the old keys are removed; a 0.3 profile needs no edit. The new `scopes.defaultScope` and `checkEnginesOnStart` have defaults.
- Behaviour change: with no `scope`, the search now covers the whole computer instead of the current workspace (`scopes.defaultScope` defaults to `all`); set it to `workspace` for the old behaviour.
