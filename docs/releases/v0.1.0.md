## Highlights

First public release of the native DSH Host plugin for read-only local search.

## What's included

- `local_search_files` for Everything filename/path search (`es.exe`).
- `local_search_content` for Anytxt document-content search across PDF, DOCX, XLSX, PPTX, EPUB, RTF, TXT, and MD.
- `local_search_fragments` and `local_search_read` for snippets and extracted text.
- `local_search_status` for engine health and configured roots.
- `workspace`, `work`, `personal`, and `all` scopes; `engine: auto|everything|anytxt`.
- Self-describing content refs (`anytxt:<fid>`) so a future content engine cannot collide with Anytxt ids.

## Install

```sh
dsh plugin --profile <profile> add @fishdivinity/dsh-local-search
```

## Requirements

- Windows.
- DeepSeek Harness `>=0.2.1-0 <0.3.0`.
- Everything running, with `es.exe` discoverable or configured via `esPath`.
- Anytxt Searcher GUI (`ATGUI.exe`) running for content search; `ATService` alone is not enough.

## Security

Read-only by design: fixed `es.exe` argv with the query after `--`, only Anytxt search/fragment/read methods, bounded results, and no index or settings writes.

## Known limitations

- No configuration page yet; configure through the profile `cordis.patch.yml`. A Plugins-page form is planned.
- Anytxt's terms limit personal/non-commercial use.
