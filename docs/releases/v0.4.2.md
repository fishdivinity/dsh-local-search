## 这版做了什么

- 长译文不再挤在一起：「默认检索范围」的四个选项各占各的宽度，窗口够宽就排成一行——俄语、法语、德语都一样，不会再压到相邻选项上。
- 「复制诊断」不再叫你先去提 issue：先复制给 AI 排查，解决不了，再点弹窗里那个 issue 链接。

## 怎么做到的

- 选项字段不再借用宿主的等宽分段控件，改成插件自绘的单选组：内容定宽、放不下才换行；横跨整行的字段用整行排版，不再被 560px 的格子卡住。
- 选中的高亮跟着选项自己的宽度走，不再依赖等分宽度的滑动指示牌；方向键会跳过禁用项。
- 诊断提示里的 `issue` 是链接，按占位符拼进句子，每种语言自己决定它摆在哪；提示语不再重复「家目录已换成 ~」这句，脱敏照旧。

## 升级

```sh
dsh plugin --profile <profile> add @fishdivinity/dsh-local-search
```

## What changed

- Long translations no longer collide: the four default-scope options keep their own width and share one line whenever the window is wide enough — Russian, French and German alike, with no label painting over its neighbour.
- Copy diagnostics no longer sends you straight to the issue tracker: hand the text to the assistant first, and open the issue only if that does not solve it.

## How

- Option fields no longer borrow the host's evenly divided segmented control; the plugin draws a radiogroup whose segments take their content width and wrap only when they must. A field that spans the row uses the row instead of the 560px cell.
- The selected highlight follows each option's own width instead of a sliding indicator that assumes equal segments; arrow keys skip disabled options.
- The hint's `issue` is a link spliced in at a placeholder, so every language keeps its own word order; the hint no longer repeats the redaction note, though the redaction still happens.
